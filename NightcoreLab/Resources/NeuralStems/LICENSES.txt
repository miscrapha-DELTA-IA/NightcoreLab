# Third-party notices

This repository contains no model weights. The conversion scripts download them from their original
sources at run time. Licenses below apply to those components, not to this repository's own code
(which is MIT — see [LICENSE](LICENSE)).

| Component | Used for | Source | License |
|---|---|---|---|
| Demucs v4 (htdemucs) — code and pretrained weights | The separator being converted; `convert_core.py` reuses `HTDemucs.forward` with the spec calls replaced, and `stemcommon.py` reproduces `_spec`/`_ispec`/`_magnitude`/`_mask` | [facebookresearch/demucs](https://github.com/facebookresearch/demucs) | MIT, © Meta Platforms, Inc. |
| coremltools | PyTorch → Core ML conversion | [apple/coremltools](https://github.com/apple/coremltools) | BSD-3-Clause, © Apple Inc. |
| PyTorch / torchaudio | Reference implementation and export | [pytorch/pytorch](https://github.com/pytorch/pytorch) | BSD-3-Clause |
| einops | Tensor rearrangement inside the copied forward | [arogozhnikov/einops](https://github.com/arogozhnikov/einops) | MIT |
| MUSDB18 (previews) | Quality measurement in `musdb_sdr.py` (not redistributed) | [sigsep/sigsep-mus-db](https://github.com/sigsep/sigsep-mus-db) | Dataset is licensed for non-commercial research use — check before using it in a commercial context |

Notes:

* **Demucs weights are MIT**, which is what makes on-device separation usable in a commercial app.
  Include this notice (or an equivalent attribution) in your app's acknowledgements.
* `convert_ft.py` targets `htdemucs_ft` — the same MIT weights, four fine-tuned models instead of one.
* BS-RoFormer is intentionally **not** included here. The architecture and training code
  ([ZFTurbo/Music-Source-Separation-Training](https://github.com/ZFTurbo/Music-Source-Separation-Training),
  [lucidrains/BS-RoFormer](https://github.com/lucidrains/BS-RoFormer)) are MIT, but the widely used
  community checkpoints have unclear licensing, so nothing that depends on them ships here.
