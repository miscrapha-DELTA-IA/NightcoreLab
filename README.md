# Gnarly Beta

Catálogo público de instalação e atualização do Gnarly no LiveContainer.

Adicione esta URL em **Sources/Fontes → +**:

```text
https://raw.githubusercontent.com/miscrapha-DELTA-IA/NightcoreLab/gnarly-beta/source.json
```

As versões do catálogo apontam para IPAs publicados nas [releases do projeto](https://github.com/miscrapha-DELTA-IA/NightcoreLab/releases). Os arquivos de instalação, notas e SHA-256 acompanham cada release.

A configuração inicial do LiveContainer + SideStore segue o [guia oficial](https://livecontainer.github.io/docs/installation/lc_sidestore). Os dados ficam no contêiner do LiveContainer, separados da instalação nativa do Gnarly.
